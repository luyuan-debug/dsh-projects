# 目录选择

任务需要本地目录时，从任务卡片打开系统目录选择器。选择并连接目录后，仍需单独批准任务执行。

## 等待与取消

等待时可以点击“取消目录选择”，继续操作项目。关闭、修改或拒绝任务，或切换项目，也会取消这次选择。之后返回的旧结果不会应用到已变化的任务。

服务端最多等待 120 秒，客户端另有 125 秒兜底。

取消后，系统窗口可能仍在关闭。请在实际窗口中取消，或稍后重试；旧窗口结束前不能再次打开选择器。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 没有出现系统窗口 | 取消等待后重试，检查是否为适配的本机 DSH 环境 |
| 提示已有选择器 | 关闭原系统窗口后重试 |
| 等待超时 | 重新选择目录，检查执行端是否可用 |
| 任务已经变化 | 返回当前任务卡片重新选择 |
| 窗口尚未关闭 | 在系统窗口中取消，或稍后再试 |

取消、超时和目录连接都不会自动授予任务执行权限。
