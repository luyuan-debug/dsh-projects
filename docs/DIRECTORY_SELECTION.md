# 选择任务目录

目录选择用来连接你在本机系统窗口中确认的文件夹。**选择和连接都不等于授权任务执行**：选好后仍需确认目录、Direct / Worktree 模式以及“仅允许本线程”或项目后续任务的授权范围。

## 正常选择

在任务授权卡片点击“添加文件夹”或“更换文件夹”，在系统窗口选定目录。也可以在项目设置的“环境”页使用“选择本机文件夹”，先连接文件夹，再为具体任务选择并确认。

等待期间，页面显示目录选择状态和“取消目录选择”。其他项目操作可以继续使用，拒绝或修改任务也不需要等待选择器返回。

## 系统窗口没有出现

可以查找独立的系统目录窗口；它不一定是主 App 内的弹出面板。如果没有可操作窗口，直接点击页面上的“取消目录选择”，无需为了让页面恢复而重启 DSH。

取消会立即结束页面等待，并向后端请求关闭本次系统选择器。任务授权保持原状。关闭相关界面、拒绝或修改任务、切换项目也会取消本次选择；之后迟到的目录不会自动应用到旧任务。

## 最长等待多久

服务端的选择等待上限是 **120 秒**。如果服务响应未能正常到达，客户端还有 **125 秒**兜底，会停止本地等待并请求取消。提示超时后可以检查系统窗口、取消它，再重新选择。

超时或取消不等于系统窗口必定已经消失。它们表示本次逻辑选择不再有效，不能继续为旧任务应用目录或授予权限。

## 提示已有选择器或取消未确认

同一执行端一次只保留一个尚未结束的系统选择器。若后端未能及时响应关闭，旧窗口可能仍在关闭；重复选择会立即给出提示，避免再开一个窗口。其他项目命令仍可继续。

| 提示 | 处理方式 |
| --- | --- |
| 上一次系统选择器仍在关闭 | 找到旧系统窗口并取消，或等其结束后重试。不要连续重复点击。 |
| 未能确认系统选择器已关闭 | 页面已经停止等待，但取消回执未成功。取消实际系统窗口后重试，其他操作仍可使用。 |
| 目录选择请求暂时达到上限 | 稍后重试；不要通过反复点击增加请求。 |
| 目录选择请求无效 | 刷新界面后重新选择。 |
| 执行端没有可用原生选择器 | 先核对是否为适配的本机 DSH 环境，按兼容性报告排查。 |

错误详情保留可核对的错误代码。取消操作不会隐藏之前的选择错误；实际选择成功后才更新相应结果。

## 任务在等待期间变了

返回的目录只能应用到发起选择时的那个任务请求和版本。若你已经修改工作区模式、拒绝任务、关闭卡片或切换项目，旧选择会取消或被忽略，不会拿迟到结果覆盖新选择。

如果提示任务版本已经变化，先核对任务当前状态，再从当前卡片重新选择。不要把“目录已经连接”当作任务已经获准执行。

## 验证范围

本说明适用于 **v0.3.0-rc.1**。等待、取消、超时及迟到保护已经过相关验证；**原生选择指定目录并完成后续任务授权的完整成功流程尚未完成验证，状态为 PARTIAL**。不能将取消成功解释为整个目录流程通过。

固定 DSH 构建、平台与验证范围见 [兼容性](COMPATIBILITY.md) 和 [发布维护](RELEASE.md)。其他宿主构建尚未验证，官方 Agent Team 的使用限制保持不变。
