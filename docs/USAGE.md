# 使用指南

适用于 **DSH Projects v0.3.0-rc.1**，已验证环境为 macOS arm64 / DSH `0.2.1-rc.2`。首次使用请先完成 [安装](INSTALL.md)，从旧版升级先阅读 [迁移说明](MIGRATION.md)。

> 当前版本不支持 DSH 官方 Agent Team。请勿在项目主对话或 Thread 中选择 Team 预设。同一 Profile 共装尚未验证，详见 [兼容性说明](COMPATIBILITY.md#agent-team)。

## 创建项目

打开 **Projects**，填写项目目标与项目指令，选择已在 DSH 配置的模型。未配置模型时也可以先创建项目，开始对话前再完成模型设置。

在主对话中提出任务。Coordinator 可以回答问题、创建独立 Thread，或继续已有 Thread。在 Overview 查看任务状态，进入 Thread 后可直接续聊。

## 工作目录与停止操作

需要读写本地文件时，确认授权卡中的目录、模式与范围：

- **Direct：** 直接使用已有目录，修改会写入该目录。
- **Worktree：** 基于可用的 Git 仓库创建工作区。
- **仅允许本线程：** 授权不自动扩展到后续任务。
- **项目范围：** 授权仅覆盖同一目录与模式。

连接文件夹不等于已经授予执行权限；模型、文档和记忆内容都不能代替你的授权。目录选择等待可取消，服务端 120 秒超时、客户端 125 秒兜底，旧任务的迟到结果不会覆盖新任务。原生指定目录完整成功流程仍未完成验证，操作与恢复方法见 [目录选择](DIRECTORY_SELECTION.md)。

Thread 使用 DSH 原生输入、模型选择、审批和停止控件。在已验证的 DSH 构建中，连续按两次 **Esc** 可停止执行；弹层打开时，Esc 会先处理弹层。输入框有草稿时，“排队发送”按钮不代表任务已经结束。

文字草稿可以恢复。未发送的文件或图片附件不保证在退出应用、停用或卸载后保留，请提前发送或另存。

## 选择工具

打开 **项目设置 → 环境 → 使用已有工具**。

Coordinator 保留项目管理与共享资料工具；Thread 默认允许 `read`、`write`、`edit`、`bash`、`workspace_commit`，可以额外选择只读检索工具 `glob`、`grep`。检索限制在已授权的工作区内。

保存后，尚未执行的调用会重新检查权限。已经开始的操作不会回滚，需要中断时使用 DSH 的停止操作。工具选择仍受目录许可、角色、Git 保护和原生审批限制。其他暂不支持的工具会显示不可用原因。

## Memory：保存项目约定

默认使用 **Standard** 本地记忆，不连接 `Hindsight`，也不为本地检索调用外部服务。

记忆以逻辑 Markdown 文件管理：`MEMORY.md` 提供索引，概要、需求、约束、决定、问题和经验分别保存正文。这些文件由插件 Store 管理，不会在用户仓库内创建同名文件。

在 Memory 中保存、编辑或删除条目，查看来源与修订。当前内容、候选、已替代和归档分开；同一主题有新决定时，旧记录保留为历史，不继续标作当前要求。编辑发生版本冲突时，不会直接覆盖较新的内容。也可以在对话中明确提出“记住”或“忘记”，由模型调用相应工具；自然语言识别采用保守规则，不能保证自动识别每一种说法。

发送新任务或续聊时，插件会按预算整理项目记忆。概要和相关正文优先，索引提供名称、主题、类型、状态、修订及字面短说明。短说明只取首个非空行的前 100 个 Unicode 字符，保留符号并标记多行或截断；采用具体约定前，应按逻辑路径读取全文，避免遗漏后文的条件或否定。

### 查看本轮提供了什么

**Used This Turn** 将“索引预览（非全文）”和“已提供全文”分开展示，也列出来源资料及可选 `Hindsight` 历史引用。省略、截断、分页和降级原因会一并记录。

使用记录展示当次组装的内容，不表示请求一定发送成功，也不保证模型会遵循。候选内容和外部历史仍需自行确认。

### 检索工程和 Library

本地检索使用中文词片段、英文词和代码符号进行词法匹配，不提供通用语义理解。工程索引需明确确认目录与范围，仅读取已授权文本；同项目不同工作树的代码证据隔离，项目共享决定保持共享。来源自动召回默认关闭，读取与上下文均有容量上限。

### 忘记与隐私

忘记不会删除已有会话、原文件或生成文件中的旧引用。Library 资料也可以单独排除索引。

启用 `Hindsight` 后，忘记会先本地抑制并暂停增强，以免远端派生历史再次注入；删除远端文档有额外限制，断开连接不删除整个库。私有 Thread、资料和记忆的范围不会因为共享记忆库而自动扩大。

## `Hindsight`：按需补充历史

需要外部历史时，在 **项目设置 → 记忆 → 高级记忆（可选）** 配置已有 `Hindsight` `1.1.0` 服务，并为该项目绑定一个明确的 bank。已有库默认只读；先检查服务和库权限，再显式开启历史召回。写回已完成任务报告需要单独开启。

检查中会清除旧成功结论；服务不可达、健康异常和库访问失败分别显示，历史成功时间不会代替本次检查。真实 Recall / Retain 及模型效果尚未验证，使用前请阅读 [`Hindsight` 设置](HINDSIGHT.md)，核对数据出口、费用和范围。

## Library：整理参考资料

Library 支持导入文件或文件夹、预览、替换、下载原文件及移除。支持内容包括：

- PDF 页码和文本层、PNG/JPEG 图片。
- DOCX 段落与表格。
- XLSX 单元格、公式缓存、隐藏与合并信息。
- PPTX 正文、表格与可选讲者备注。

内容可能分页或截断，请留意读取范围提示。没有 OCR、公式计算、宏执行或完整 Office 排版还原，详见 [已知限制](KNOWN_LIMITATIONS.md)。

预览在本机执行，不调用模型。让模型读取资料时，内容可能发送给所选服务商；读图需要模型声明支持图片，插件不会自动切换到其他模型。实际图片理解尚未验证。

## 暂停、归档与删除

- **暂停：** 阻止项目继续执行。
- **归档：** 保留历史和资料，可恢复。
- **删除：** 确认后清理插件的项目关联、Memory、Library 副本及授权，并归档保留 DSH 会话历史。用户原文件、仓库和 Worktree 不删除。

停用或卸载后 Projects 入口关闭，但不会自动清空项目数据。需要清理时，先在 Projects 中删除项目。`Hindsight` 中已接收的操作可能继续，远端库默认保留。升级和恢复步骤见 [升级与回退](MIGRATION.md)。
