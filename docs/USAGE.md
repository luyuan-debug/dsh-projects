# 使用指南

适用于 DSH Projects `0.1.0-rc.1`，已验证环境为 macOS arm64 / DSH `0.2.1-rc.2`。首次使用请先完成 [安装](INSTALL.md)。

> 当前版本不支持 DSH 官方 Agent Team。请勿在项目主对话或 Thread 中选择 Team 预设。同一 Profile 共装尚未验证，详见 [兼容性说明](COMPATIBILITY.md#agent-team)。

## 创建项目

打开 **Projects**，填写项目目标与项目指令，选择已在 DSH 配置的模型。未配置模型时也可以先创建项目，开始对话前再完成模型设置。

在主对话中提出任务。Coordinator 可以回答问题、创建独立 Thread，或继续已有 Thread。在 Overview 查看任务状态，进入 Thread 后可直接续聊。

## 工作目录与停止操作

需要读写本地文件时，确认授权卡中的目录、模式与范围：

- **Direct：** 直接使用已有目录，修改会写入该目录。
- **Worktree：** 基于可用的 Git 仓库创建工作区。
- **仅允许本线程：** 授权不自动扩展到后续任务。
- **项目范围：** 授权仅覆盖同一目录与模式。

连接文件夹不等于已经授予执行权限；模型、文档和记忆内容都不能代替你的授权。

Thread 使用 DSH 原生输入、模型选择、审批和停止控件。在已验证的 DSH 构建中，连续按两次 **Esc** 可停止执行；弹层打开时，Esc 会先处理弹层。输入框有草稿时，“排队发送”按钮不代表任务已经结束。

文字草稿可以恢复。未发送的文件或图片附件不保证在退出应用、停用或卸载后保留，请提前发送或另存。

## 选择工具

打开 **项目设置 → 环境 → 使用已有工具**。

Coordinator 保留项目管理与共享资料工具；Thread 默认允许 `read`、`write`、`edit`、`bash`、`workspace_commit`，可以额外选择只读检索工具 `glob`、`grep`。检索限制在已授权的工作区内。

保存后，尚未执行的调用会重新检查权限。已经开始的操作不会回滚，需要中断时使用 DSH 的停止操作。工具选择仍受目录许可、角色、Git 保护和原生审批限制。其他暂不支持的工具会显示不可用原因。

## Memory：保存项目约定

在 Memory 保存、编辑或删除条目，查看来源与版本。也可以在主对话中明确提出“记住”或“忘记”，由模型调用相应工具。

删除条目不会抹除已有会话、生成文件中的旧引用。编辑发生版本冲突时，不会直接覆盖较新的内容。

## Library：整理参考资料

Library 支持导入文件或文件夹、预览、替换、下载原文件及移除。支持内容包括：

- PDF 页码和文本层、PNG/JPEG 图片。
- DOCX 段落与表格。
- XLSX 单元格、公式缓存、隐藏与合并信息。
- PPTX 正文、表格与可选讲者备注。

内容可能分页或截断，请留意读取范围提示。没有 OCR、公式计算、宏执行或完整 Office 排版还原，详见 [已知限制](KNOWN_LIMITATIONS.md)。

预览在本机执行，不调用模型。让模型读取资料时，内容可能发送给所选服务商；读图需要模型声明支持图片，插件不会自动切换到其他模型。实际图片理解尚未验证。

## 暂停、归档与删除

- **暂停：** 阻止项目继续执行。
- **归档：** 保留历史和资料，可恢复。
- **删除：** 确认后清理插件的项目关联、Memory、Library 副本及授权，并归档保留 DSH 会话历史。用户原文件、仓库和 Worktree 不删除。

停用或卸载后 Projects 入口关闭，但不会自动清空项目数据。需要清理时，先在 Projects 中删除项目。升级和恢复步骤见 [升级与回退](MIGRATION.md)。
