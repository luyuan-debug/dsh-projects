# DSH Projects 本地插件使用说明

本包版本 **0.0.0-final01.5**。已验证宿主为 macOS arm64 上的 DSH 0.2.1-rc.2，构建 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。不修改或替换 DSH；完整 Claude 对标、真实模型语义验收仍未完成。

## 安装与正常启动
1. 解压本 ZIP，保留 `artifacts/product.tgz`。打开正常 DSH 的“插件”页，选择“安装第三方插件”，输入此 tgz 的完整 `file:` 路径，安装后点击“立即启用”。包名沿用 `dsh-project-threads-wave1-spike`，界面入口为 **Projects**。
2. 等组件实际显示“运行中”。插件会对启动时短暂的元数据 404/503 做有界重试，不会重放写操作或模型请求。本轮测试没有替你安装到生产 Profile。
3. 正常安装不需要审计环境变量。模型仍由 DSH 管理：在新建项目/项目设置选择你已经授权的提供方和模型。未配置模型可以先创建项目，但执行前需要配置；测试夹具不属于生产安装包。

## 首次任务与目录
在 Projects 创建项目，保存目标、项目指令和模型。在主对话提出工作，协调器可以回答、创建独立 Thread 或继续已有 Thread。没有目录授权时会保留请求并显示授权卡。

选择你要让任务工作的目录，核对 Direct/Worktree 模式与范围。“仅允许本线程”不扩到后续任务；项目范围许可只覆盖同一目录与模式。Direct 会共享现有文件；Worktree 需要可用 Git 仓库。模型、文档和记忆都不能授予目录权限。不要把连接文件夹误当成完成授权。

打开 Thread 使用 DSH 原生输入、模型、审批与停止控件。当前固定构建的停止快捷键是 **连续两次 Esc**；非空草稿时主按钮可能显示“排队发送”，不代表任务结束。弹层内 Esc 先处理弹层。草稿和临时附件在插件内切换及宿主面板往返已验证保持；未发送 File/图片不是跨应用重启的持久文件，停用/退出前请发送、另存或移除。

## 使用已有工具
项目设置 → 环境 → 使用已有工具。协调器保留项目管理与共享资料能力；Thread 原有 read/write/edit/bash/workspace_commit 允许集保留，可选择宿主只读 glob/grep。检索仅在当前已授权工作区，拒绝自定义外部根目录和跟随链接扩权。

保存后对后续及尚未执行的调用重新检查；已开始的操作不会被回滚，需停止当前工作时使用原生 Stop。工具选择仍与 Host、目录许可、角色、Git 保护及原生审批相交。不会切换全局插件开关，也不会改变普通会话或其他项目。目录中未核证约束的 Host/MCP 工具会显示不可用原因，不代表已完成 MCP 接入。

## Memory 与 Library
Memory 是真实项目条目，带来源、版本、CAS、编辑与忘记。主对话明确说“记住/忘记”可由模型调用对应工具；已有会话和已生成文件中的旧引用不会随“忘记”消失。没有假的 MEMORY.md 文件入口。项目设置、单条记忆分别保存；冲突不会覆盖当前编辑。

Library 支持文件/文件夹导入、按需预览、替换、下载原字节和移除。实际支持 PDF 物理页/文本层、PNG/JPEG、DOCX 段落表格、XLSX 单元格/公式缓存/隐藏与合并信息、PPTX 正文表格/可选讲者备注。提供分页/范围、截断及不支持项说明。没有 OCR、公式计算、宏执行或通用 Office 保真排版。

预览在本机执行，不调用模型。会话读图需当前模型声明图片能力；实际模型调用可能发送资料到你选定的提供方。模型不支持图片时明确拒绝，不自动切换模型。外部文档后端未安装/接通时使用现有 reader；安全、授权、版本、完整性与取消拒绝不会靠回退绕过。

## 暂停、归档、删除与卸载
暂停阻止项目执行；归档保留历史与资料，可恢复。删除需要明确确认：清理插件拥有的关联、Memory、Library 副本并撤销该项目许可，**归档保留 DSH 会话历史**。用户原文件、仓库和 Worktree 不删除。

停用/卸载后 Projects 入口消失，普通原生会话仍可使用。项目自有数据与 DSH 历史不会被“卸载插件”隐式清空；需要清项目数据时使用项目删除流程。重新启用会恢复既有项目。未知错误先看组件状态和原始错误详情，不要用重建项目、放宽权限或切换提供方掩盖。

## 尚未接通的能力
当前只有宿主提醒的项目会话关联和真实任务页入口，**没有确定性自动创建项目 Thread 的 Routine**。通知为应用内提示，不是 OS 推送。没有真实外部 MCP/reader、完整 PR/CI 或多可写仓库编排验收。真实模型测试没有新增预算，本轮使用脚本夹具验证控制/数据链路，不证明模型理解。

## 数据、升级与回退
默认受管数据根由实际 DSH_HOME/Profile 与标准 XDG_DATA_HOME 派生，位于 `dsh-project-threads/<身份哈希>`；元数据由对应 DSH_HOME 的 storage-domain 管理。升级前暂停项目、停止任务、正常退出 DSH，一致备份插件数据根及其 `project_threads_*` 命名空间存储，不复制账号配置或凭据。

旧数据沿用原 ID/cwd/grant/snapshot；不自动搬迁绝对路径。历史审计 Profile 应保留原受管路径配置，不能仅删掉配置就假定跨目录迁移完成。回退须恢复同路径、同 Profile、已静止的配套快照。旧版不了解新工具撤销策略；依赖该限制时不得把旧包恢复后直接启用执行。保留新版与备份进行诊断，避免静默扩权。
