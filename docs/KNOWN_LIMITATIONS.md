# 已知限制

## Agent Team

**当前版本不支持 DSH 官方 Agent Team。** 不要在 Project 主对话或 Thread 中运行 Team、选择 Team 预设，或通过 Coordinator 调度 Team 成员。同一 Profile 共装未经过兼容性测试；需要两者时，请分别使用独立 Profile。工具过滤不等于预设拦截，当前没有专门的 Team 预设错误提示。详见 [兼容性说明](COMPATIBILITY.md#agent-team)。

## 平台与模型

- 已验证环境为 macOS arm64、DSH `0.2.1-rc.2`，具体构建见 [兼容性](COMPATIBILITY.md)。其他构建和额外复杂预设未验证。
- 本地核心流程的测试使用脚本模型。实际模型的任务完成质量、工具选择质量和图片理解尚未验证。
- 支持显示图片、向模型传递图片，与模型正确理解图片是不同的能力。

## 工具与自动化

- Thread 默认允许 `read`、`write`、`edit`、`bash`、`workspace_commit`，可额外选择 `glob`、`grep`。Coordinator 保留项目协调工具，不开放普通开发工具。
- 真实外部 MCP 尚未接通；其他不受支持的宿主工具不能通过项目设置启用。
- 可关联 DSH 提醒和任务入口，但没有自动创建 Thread 的 Routine，也未实现跨重启的自动派工。
- 通知仅为应用内提示，不是系统推送。多个同时发生的事件可能合并显示，请以项目列表状态为准。
- 没有插件内 PR/CI 协作、多可写仓库管理或云端 Worker。仓库自身的 GitHub Actions 不属于插件功能。

## 文档读取

| 格式 | 支持内容与限制 |
| --- | --- |
| PDF | 读取物理页和文本层；扫描件不提供 OCR |
| PNG / JPEG | 本地预览与图片传递；实际模型理解未验证 |
| DOCX | 段落和表格，不保证还原完整排版 |
| XLSX | 单元格、公式缓存、隐藏与合并信息；不重新计算公式 |
| PPTX | 正文、表格和可选讲者备注；不保证还原复杂图表与版式 |

读取结果可能分页或截断，以界面和工具返回的范围说明为准。不支持旧版 Office、加密容器或宏执行。额外的外部文档读取服务尚未验证。

## 数据与恢复

- 删除 Memory 条目不会删除会话历史或已生成文件中的旧引用。
- 删除项目会清理插件数据，归档保留 DSH 会话历史。用户原文件、仓库和 Worktree 保留。
- 卸载插件不会自动删除项目数据。
- 文字草稿可恢复；未发送的文件和图片附件不保证在退出应用或卸载后仍然保留，请提前发送或另存。
- 升级与回退需要配套的数据备份，步骤见 [升级与回退](MIGRATION.md)。
