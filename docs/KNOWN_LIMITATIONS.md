# 已知限制

适用于 **DSH Projects v0.3.0-rc.1**。本版本为预发行版。测试结果按离线、DSH Host、原生 Desktop、真实服务和真实模型分别记录，详见 [验证范围](RELEASE.md)。

## 项目记忆

- Standard 默认不启用 Hindsight。本地记忆管理与词法检索不会探测外部服务，不发出 Hindsight HTTP 请求；DSH 对话模型及其他插件是否联网由各自配置决定。
- 自然语言决定采用当前用户来源、精确引用与保守意图规则。转述、假设和征求批准仍可能进入候选，不保证抽取全部事实，也不保证识别所有表达。
- 本地检索采用中文词片段、英文词、代码符号和 BM25 词法匹配。Godot、.NET 与 workflow 只扩展受支持的文本读取和定位，不提供完整 AST、通用语义或跨语言理解。
- 正常 `auth.ts`、`tokens.ts`、`cookie_parser.py` 等源码不因文件名本身被当作凭据。真实凭据数据、高置信敏感正文、符号链接、未授权目录和缓存仍排除；有限规则不保证发现所有秘密。
- 逻辑文件由 Store 管理，不在用户仓库创建同名文件。当前、候选和历史分开；历史与待解决问题不能当成已确认的当前要求。
- 自动来源召回默认关闭，工程索引需明确确认授权范围。读取、文件数、字节、分块和上下文均有上限，遗漏与跳过原因以返回说明为准。
- 索引短说明只取首个非空字面行的前 100 个 Unicode 字符，保留符号，不作语义总结；多行或截断会标记。否定与条件可能在后文，采用具体约定前须读取对应逻辑文件。分页或预算不足时，不会注入全部条目。
- Used This Turn 分开记录索引预览与已提供全文，只证明内容已组装到本轮上下文，不证明模型请求发送成功、模型理解或用户批准。持久记录不另存预览说明、标题或 Hindsight 历史全文；已经发送的正文仍可能存在于 DSH 正常聊天历史中。

## Hindsight 历史补充

- 适配 Hindsight `1.1.0` 接口。连接和上下文测试使用可控 HTTP 服务与脚本模型；**真实 Hindsight Recall / Retain 和真实模型效果尚未验证**。健康响应、离线测试或安装成功不能替代真实读写验证。
- 一个 Project 绑定一个明确 bank。已有库需确认整库属于本项目，默认只读，不修改库的 profile、指令或模型配置。同一服务的同一 bank 不默认供多个项目共用。
- 外部历史不是指令或当前决定。本地正式记忆更优先，实际代码与测试仍需核对。明确跨项目、私有范围、已知过时、被抑制和超预算结果会排除；未知语义冲突不保证自动识别。
- 本机 API 不等于本机模型。embedding、LLM、重排、后台归并及新库模板可能外发或收费；路线未知时不发送 Recall、Retain 或建库请求。插件不部署服务、不管理模型或数据库，也不直接调用 Reflect。
- 写回需单独开启并确认任务经验共享，只处理符合条件的终态报告，不补传全部历史，不批量复制源码、项目指令或聊天。私有 Thread、Library 和记忆的索引预览也受外发限制。
- 写回 `accepted` 不等于 `completed`，两者都不证明已能召回。未知结果先核对原 operation/document，不换随机 ID 盲发，不承诺 exactly-once 或零重复计费。
- 关闭、撤权、暂停/归档、解绑或卸载会停止新发送，并取消或失效化本地等待；远端已接收的操作可能继续。改 bank 或端点不会将旧待发项转送到新绑定。
- 忘记会先本地抑制并暂停增强，避免派生历史再次注入。它不会删除已有聊天或原文件，也不保证清除同义副本和所有远端派生观察。
- 外部库不能在此删除；只有可追踪、本插件写入且属于专属绑定的文档可再次确认后请求删除。离线或未知结果不提前报成功。断开或删除 Project 默认保留整个远端 bank。
- 若通用自动记忆 hook 重复作用于本项目，应暂停增强并检查配置，不全局卸载其他插件。
- 自动召回去重记录最多覆盖 **200 个 Session**，每个当前回合最多 **100 个消息 ID**；满后降级本地并说明原因，不通过淘汰旧记录重复请求。写回收据最多 **200 条**，满后拒绝新增并提示审查；目前没有批量清理界面。小语料测试不代表无限规模或长期高并发已验证。
- 每次连接检查独立记录服务与记忆库阶段。历史成功时间不代表本次成功；冷启动发现遗留的进行中状态时，会显示中断并要求重查。

连接步骤见 [Hindsight 设置](HINDSIGHT.md)。

## 原生目录选择

目录等待支持取消，关闭、拒绝或修改任务以及切换项目会使本次选择失效；服务端 120 秒超时，客户端 125 秒兜底，其他项目命令不再跟着等待。选择目录后仍需单独确认任务执行权限。

取消只结束逻辑请求并要求后端关闭。若后端没有及时响应，物理系统窗口可能暂时仍在；结束前新选择会立即提示已有选择器，不会多开窗口。取消回执不能证明物理窗口已经消失。

**原生“选择指定目录并完成后续授权”的完整成功流程尚未完成验证，状态为 PARTIAL。** 已验证的等待、取消、超时及迟到保护不能替代这项完整流程。具体操作见 [目录选择](DIRECTORY_SELECTION.md)。

## Agent Team

**当前版本不支持 DSH 官方 Agent Team。** 不要在 Project 主对话或 Thread 中运行 Team、选择 Team 预设，或通过 Coordinator 调度 Team 成员。同一 Profile 共装未经过兼容性测试；需要两者时，请使用独立 Profile。

工具过滤不等于预设拦截，当前没有针对 Team 预设的专用错误提示。详见 [兼容性说明](COMPATIBILITY.md#agent-team)。

## 平台与模型

- 已验证环境为 macOS arm64、DSH `0.2.1-rc.2`，具体构建见 [兼容性](COMPATIBILITY.md)。其他构建和额外复杂预设尚未验证。
- 本地核心流程使用脚本模型测试。真实模型的任务完成质量、工具选择质量和图片理解尚未验证。
- 支持显示图片、向模型传递图片，与模型正确理解图片是不同的能力。

## 工具与自动化

- Thread 默认允许 `read`、`write`、`edit`、`bash`、`workspace_commit`，可额外选择 `glob`、`grep`。Coordinator 保留项目协调工具，不开放普通开发工具。
- 真实外部 MCP 尚未接通；其他不受支持的宿主工具不能通过项目设置启用。
- 可关联 DSH 提醒和任务入口，但没有自动创建 Thread 的 Routine，也未实现跨重启的自动派工。
- 通知仅为应用内提示，不是系统推送。多个同时发生的事件可能合并显示，请以项目列表状态为准。
- 没有插件内 PR/CI 协作、多可写仓库管理或云端 Worker。仓库自身的 GitHub Actions 不属于插件功能。

## 文档读取

| 格式 | 支持内容与限制 |
| --- | --- |
| PDF | 读取物理页和文本层；扫描件不提供 OCR |
| PNG / JPEG | 本地预览与图片传递；实际模型理解未验证 |
| DOCX | 段落和表格，不保证还原完整排版 |
| XLSX | 单元格、公式缓存、隐藏与合并信息；不重新计算公式 |
| PPTX | 正文、表格和可选讲者备注；不保证还原复杂图表与版式 |

读取可能分页或截断，以界面和工具返回的范围说明为准。不支持旧版 Office、加密容器或宏执行。额外的外部文档读取服务尚未验证。工程和 Library 检索的具体范围见 [文件与语言支持](FORMAT_AND_LANGUAGE_SUPPORT.md)。

## 数据与恢复

- 删除 Memory 不会删除会话历史或已生成文件中的旧引用。
- 删除项目会清理插件数据，归档保留 DSH 会话历史。用户原文件、仓库和 Worktree 保留。
- 卸载插件不会自动删除项目数据。
- 文字草稿可恢复；未发送的文件和图片附件不保证在退出应用或卸载后保留，请提前发送或另存。
- 从旧版升级需要停止、备份并显式批准迁移。回退必须恢复配套旧快照，不能让旧包读取 schema 5。步骤见 [升级与回退](MIGRATION.md)。
