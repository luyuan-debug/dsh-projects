# 已知限制

适用于 **v0.3.0-rc.1**。

## 平台与模型

- 仅验证了 macOS arm64 和 DSH `0.2.1-rc.2` 的固定构建。Windows、Linux、Intel Mac 和其他 DSH 构建尚未验证。
- 对话测试使用脚本模型，真实模型的任务质量、工具使用和图片理解尚未测试。
- 原生目录选择已测试取消、超时和迟到结果处理，完整的选择与授权流程尚未完成测试。

## Agent Team

**不支持在 Project 主对话或 Thread 中使用 DSH 官方 Agent Team。** 不要选择 Team 预设，也不要让 Coordinator 调度 Team 成员。当前没有专门拦截 Team 预设的提示。

同一 Profile 共装尚未测试。需要两者时，请使用独立 Profile。[兼容性说明](COMPATIBILITY.md#agent-team)

## 项目记忆

- Standard 记忆管理和词法检索在本地运行，不需要 `Hindsight`。DSH 对话是否联网取决于所选模型。
- 本地检索按中文片段、英文词和代码符号匹配，不具备通用语义理解，也不保证跨语言或同义表达都能命中。
- 记忆索引只显示有长度限制的首行预览，条件和否定可能在后文。使用具体约定时应读取全文。
- 自动提取可能遗漏内容或将歧义保留为候选。候选和待解决问题不会自动成为正式决定。
- 每轮上下文有容量上限，索引和正文可能省略；使用记录会显示范围和原因。记录的是已组装内容，不保证请求已发送或模型遵循了这些内容。
- 工程索引需要授权。文件大小、数量、读取范围和上下文均有限制；符号链接、凭据、未授权目录、依赖及构建目录不参与索引。
- 删除或忘记记忆不会删除已有聊天、原资料或生成文件中的旧引用。

## 可选历史记忆

- 适配 `Hindsight 1.1.0`，真实记忆库的写入、召回和模型效果尚未测试。连接检查只检查服务健康和库访问。
- 一个项目绑定一个记忆库。已有库默认只读，写回任务报告需要单独开启；同一 bank 不应默认供多个项目共用。
- 本机 API 仍可能调用云端 embedding、重排或语言模型，产生外发和费用。路线不清楚时请保留“未知”。
- 外部历史仅作参考，不会替代当前项目决定。跨项目、私有、已过时或已抑制的内容会过滤，但无法保证识别所有语义冲突。
- 私有 Thread、Library 和记忆预览受共享限制，不会因连接同一 bank 自动获得外发许可。
- 写回“已接收”不等于处理完成，也不保证能召回。结果未知时先检查原记录，不要重复提交。
- 关闭或解绑可停止新请求，但服务已接收的操作可能继续。切换绑定不会把旧待发记录转送到新库。
- 忘记后会暂停增强，防止外部历史再次带回旧内容；不保证删除远端同义副本或派生记录。
- 断开或删除 Project 不删除整个远端 bank。只有能追踪到的插件写入文档可以在确认后请求删除。
- 自动召回记录上限为 **200 个 Session、每个当前回合 100 个消息 ID**；达到上限后使用本地记忆。写回收据上限为 **200 条**，目前没有批量清理界面。

## 工具与自动化

- 暂未接入真实外部 MCP，也未提供自动派工、插件内 PR/CI 协作、多可写仓库管理或云端 Worker。
- Thread 默认工具为 `read`、`write`、`edit`、`bash`、`workspace_commit`，可另选 `glob`、`grep`。Coordinator 只保留项目协调工具。
- 通知为应用内提示，不是系统推送。多个事件可能合并显示。

## 文档读取

| 格式 | 限制 |
| --- | --- |
| PDF | 读取文字层，不提供 OCR |
| PNG / JPEG | 支持预览和图片传递，模型理解尚未测试 |
| DOCX | 读取段落和表格，不还原完整排版 |
| XLSX | 读取单元格和公式缓存，不重新计算公式 |
| PPTX | 读取受支持的正文、表格和备注，不完整还原版式 |

不支持旧版 Office、加密容器或宏执行。内容可能分页或截断，具体范围见 [文件与语言支持](FORMAT_AND_LANGUAGE_SUPPORT.md)。

## 数据与升级

删除项目会清理插件数据，归档保留 DSH 会话历史；用户仓库、原文件和 Worktree 保留。卸载插件不会自动清空项目数据，未发送的附件也不保证在退出后保留。

从旧版升级前须备份。旧程序不能直接读取新版存储，回退需要旧安装包和配套旧快照。[升级与回退](MIGRATION.md)
